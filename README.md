# Аналіз частоти слів за парадигмою MapReduce

Скрипт завантажує текст за URL-адресою, підраховує частоту слів за допомогою MapReduce та візуалізує топ-10 найчастіших слів.

## Запуск
```bash
pip install requests matplotlib
python main.py
```

## Алгоритм
1. `get_text(url)` — завантажує текст через `requests`.
2. `map_reduce(text)` — видаляє пунктуацію, приводить текст до нижнього регістру, далі:
   - **Map** — кожне слово перетворюється на пару `(слово, 1)` (паралельно, `ThreadPoolExecutor`);
   - **Shuffle** — пари групуються за словом;
   - **Reduce** — значення кожної групи підсумовуються (паралельно).
3. `visualize_top_words(word_counts, top_n=10)` — будує горизонтальну діаграму `matplotlib` і зберігає її у `top_words.png`.

## Складність
Map, Shuffle і Reduce — O(n) за кількістю слів; сортування для топ-N — O(k log k), де k — кількість унікальних слів.

## Висновки
Найчастіші слова — службові (артиклі, прийменники, сполучники: the, of, a, was, to, and…). Щоб побачити змістовні слова, варто додатково відфільтрувати стоп-слова.
